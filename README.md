---

## Project Overview

This project is a **web application that predicts loan approval** for applicants based on their financial and employment information.  
The app uses a **trained machine learning model** (logistic regression) to determine whether a loan is likely to be approved or denied.  

It demonstrates:

- Data preprocessing and feature handling  
- Machine learning model deployment  
- Building interactive applications with Streamlit  
- Predictive analytics workflow  

---

## Files in This Repository

- `app.py` — The main Streamlit application code  
- `BUS458app.ipynb` — Jupyter notebook showing development steps and model training  
- `my_model.pkl` — Serialized machine learning model  
- `feature_columns.pkl` — Feature column names used in the model  
- `requirements.txt` — Python packages required to run the app
